//Security Header Auditor

Enter a website and see which HTTP security headers it sends, with a grade and a short explanation of what each one protects against. Click any row for details and the fix.

The server makes one GET request to the address you enter, reads only the response headers and scores eight checks. It never downloads the page body and does not save the results. Requests to private, local and cloud-metadata addresses are refused (SSRF protection). Only scan sites you own or have permission to test.
